CreatorOS — 全球华人创造者社区

**现状：** 线下酒馆，不定期举办分享/社交活动，希望将线下用户线上化沉淀。

**短期目标：** 微信小程序 MVP，提供活动报名入口，促进人与人线下连接。

**中期目标：** 扩展为 H5 应用，支持更多平台触达。

**长期愿景：** CreatorOS，全球华人创造者社区。

**Why:** 线下活动已有用户基础，但缺乏线上沉淀和持续连接的工具。

**How to apply:** 产品设计应以线下活动为核心场景出发，MVP 保持精简，围绕活动报名和用户连接展开。
