开发流程严格遵循：**技术方案 → 编码 → review → 自测 → 部署**

**Why:** 用户多次强调，确保代码质量、避免返工、保护生产环境安全。

**How to apply:**
1. 大的改动前先做技术方案设计，确保思路清晰再动手
2. 代码要简洁高效，不做过度设计
3. 编码完成后先 review 代码（安全性、逻辑正确性、是否影响已有服务）
4. review 通过后自测（API 测试、前端功能验证）
5. 自测通过后才能部署到服务器
6. 服务器上有很多其他服务，部署时绝不能影响现有服务和数据
7. PostgreSQL 使用独立的 creatoros 用户和数据库，完全隔离
