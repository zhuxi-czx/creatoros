# 小程序用户隐私保护指引（填报内容）

> 用途：微信公众平台「设置 → 服务内容声明 → 用户隐私保护指引」在线填报底稿。
> ⚠️ 未配置此指引，小程序将无法调用 `wx.getUserProfile`、`wx.getPhoneNumber`、`wx.login` 等接口，且无法通过审核。
> 运营者主体：**（企业全称，待填）**；联系方式：**（客服邮箱/电话，待填）**。

## 一、开发者收集的信息及用途

| 收集的信息 | 用途 | 触发场景 | 是否必要 |
|---|---|---|---|
| 微信 OpenID / UnionID | 标识用户身份、登录账号体系 | 进入小程序时通过 `wx.login` 获取 | 必要 |
| 微信昵称、头像 | 展示个人资料、活动参与者列表 | 用户主动授权填写资料时 | 否（可拒绝） |
| 手机号 | 活动报名联系、到场核验、支付通知 | 用户主动授权 `getPhoneNumber` 时 | 否（可拒绝） |
| 所在城市、个人简介、MBTI/星座/年代等标签 | 完善个人资料、社区匹配展示 | 用户主动填写时 | 否 |
| 订单与支付信息（活动、金额、支付状态） | 完成付费报名、订单查询、退款 | 用户付费报名时 | 必要（付费场景） |

## 二、第三方信息共享

- **微信支付（财付通）**：付费报名时，向微信支付共享订单号、金额等下单必要信息，用于完成支付。
- **其他**：不向第三方 SDK 共享上述信息（如后续接入统计/客服 SDK 需在此补充）。

## 三、信息的存储与保护

- 数据存储于运营者自有服务器（中国境内，企业云服务器）。
- 采用 HTTPS 传输、JWT 鉴权、数据库访问隔离等措施保护信息安全。
- 支付证书/密钥不入库、不公开，仅服务端安全持有。

## 四、用户权利

- 用户可在「我的 → 编辑资料」修改或删除其昵称、头像、城市、简介等资料。
- 用户可通过客服联系方式申请注销账号、删除个人信息。
- 用户可拒绝非必要授权（昵称/头像/手机号），不影响浏览活动等基础功能。

## 五、其他

- 本指引随功能更新而更新，更新后将在小程序内提示。
- 未成年人使用须在监护人指导下进行。
