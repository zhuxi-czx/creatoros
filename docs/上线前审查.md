## 二、评估为「不阻塞上线」（附理由，留作 backlog）

- **支付回调防重放**：用 AES-256-GCM 解密（伪造需微信 APIv3 密钥）+ confirmPaid 乐观锁幂等，重放真实回调无副作用。**建议后续加 Wechatpay-Timestamp ≤5 分钟校验**作深度防御。
- **管理员密码明文比对（timing attack）**：admin-login 5 次/分/IP 限流已让 timing attack 实际不可行。可后续改 `crypto.timingSafeEqual`（hash 后比对）。
- **付费下单的 PlanF 专享/会员资格事务内二次验证**：专享活动走免费报名接口（已事务内拦截），付费下单走专享极罕见，窗口极小。
- **退款路径未退还 GUEST_FREE 名额**：仅「大咖分享 + price=0」误配的边缘场景才会创建 usage。
- **JWT 7 天无主动吊销**：但 jwt.strategy 每次请求查库验用户 status，封号即时生效。可后续缩短有效期或加 token 版本号。
